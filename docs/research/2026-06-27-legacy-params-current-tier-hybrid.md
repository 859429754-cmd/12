# 早期五档、当前五档与旧参数混合试验

以后以本报告为准：早期 DeepSeek 五档、当前五档和“旧策略参数 + 当前五档规则”是三类不同实验。不能只看收益率最高的一组直接上线。

本轮没有调用 DeepSeek，没有修改云端实盘配置，没有修改 TradingView 对齐策略合同。

## 优缺点对比

### 早期 DeepSeek 5档

优点：

- 在旧 313 样本上结果最强：`4898.28%`、DD `-58.51%`、PF `1.619`。
- 它是真实 DeepSeek 审查 replay，不是离线规则代理。
- 相比旧纯策略，收益、回撤、PF 全部改善。

缺点：

- 只证明旧 `VOL=2.0` 样本有效，不等于当前 `VOL=2.5` 实盘有效。
- 旧 DeepSeek 的历史新闻、订单流、提示词、模型状态和当前云端不完全一致。
- 没有完整 walk-forward 灰度记录，不能直接大资金上线。
- 旧五档如果直接回退，可能和当前 DeepSeek 缓存、主备 API、新闻背景系统、账户跟随系统不一致。

### 当前五档

优点：

- 和当前云端实盘架构一致。
- 风控更稳定，当前 2022-2026 样本中旧保守五档回撤 `-34.75%`，2020-2026 扩样本回撤 `-39.36%`。
- 可以和当前订单生命周期、重大新闻方向闸、账户跟随、shadow ledger 体系直接兼容。

缺点：

- 当前旧保守五档在 291 样本里收益低于纯策略：`1682.30%` vs 纯策略 `2463.45%`。
- 它偏防守，不是理想的扩盈模型。
- calibrated v2 收益更高，但还没达到大资金无人值守直接替换标准。

### 旧参数 + 当前五档混合

优点：

- 可以复刻旧 313 样本，交易数和旧 DeepSeek 实验一致。
- 当前规则在旧参数样本上会显著降低回撤。
- PF 高，说明过滤后的交易质量更好。

缺点：

- 当前规则是按 `VOL=2.5` 研究出来的，直接套到 `VOL=2.0` 会偏保守。
- 当前 `volume_score` 等阈值仍以 2.5 为中心，旧参数信号会被低估。
- 本轮订单流只回填到 `210/313`，完整结论需要长任务补齐。

## 混合试验结果

### 旧参数纯策略复刻

命令：

```powershell
python scripts\pure_strategy_tier_research.py --start 2022-01-01 --end 2026-05-21 --source binance --initial-equity 10000 --leverage 4 --fee-rate 0.0006 --slippage-bps 2.0 --volume-multiple 2.0 --kc-scalar 2.8 --atr-stop-multiple 1.5 --position-fraction 1.0 --output data\research\legacy_params_vol20_pure_strategy_eth_2022_20260521.json
```

结果：

- 交易数：`313`
- 纯策略收益：`1276.21%`
- 与旧 DeepSeek 实验的纯策略收益完全对齐。

### 旧参数 + 当前规则，部分订单流 210/313

订单流回填：

- 60m usable：`210/313`
- 240m usable：`210/313`
- 剩余未覆盖信号按中性处理。

解释：

- 旧参数配当前规则后，当前规则明显更防守，收益低于旧 DeepSeek 5档。
- PF 和回撤更好，说明当前规则更像风险过滤器。
- 订单流缺失时，当前旧保守/v2/v2.1 会收敛到近似结果，说明订单流是区分这些模型的重要因子。

## 专业结论

1. 旧 DeepSeek 5档收益最高，但不能直接回退上线，因为它依赖旧参数和旧 DeepSeek replay。
2. 当前五档更适合大资金无人值守，因为它更贴近当前云端风控和实盘执行链路。
3. “旧参数 + 当前规则”可以作为研究方向，但本轮结果不支持直接替换当前实盘策略。
4. 如果要继续研究旧参数组合，必须先完成旧参数 313 笔订单流全覆盖，再重新跑当前规则和 walk-forward。
5. 如果目标是提高收益，当前更现实的方向不是回退旧参数，而是在当前 `VOL=2.5` 策略上灰度 `calibrated_v2_loss_aware`，并用 shadow ledger 追踪真实 DeepSeek 是否能复现类似分档质量。

## 下一步建议

- 生产默认：继续当前旧保守五档。
- 小资金灰度：`calibrated_v2_loss_aware`。
- 研究任务：补齐旧参数 313 笔订单流，复刻旧 DeepSeek 5档和当前规则的同 ledger 对照。
